# 思忆集浏览器助手 MVP

这是一个面向 Chrome / Edge 的 Manifest V3 侧边栏扩展。

## 当前能力

- 读取当前页 URL、标题、选中文本、可见正文
- 调用思忆集桌面端本地回环接口做 AI 总结
- 在侧边栏显示摘要、关键点、上下文建议
- 一键发送到收件箱
- 一键转成笔记
- 一键生成任务
- **划词加入生词本**（v0.4+）— 在网页上选中英文词或短语，右键 → 「加入思忆集生词本：xxx」，直接进默认词本
- 可在侧边栏直接修改桥接地址并保存到本地扩展配置
- 可查看桌面端桥接状态、工作台概览和诊断建议
- 可通过独立设置页查看最近连接记录、测试桥接地址并恢复默认配置
- **UI/UX 升级**（v0.5.0）— 侧栏与设置页统一品牌视觉（渐变品牌标 + SVG 线性图标工具栏），emoji 图标全部替换，工具栏改为面板内横向布局，全面跟随系统深/浅色模式
- **侧栏聊天提问修复**（v0.5.0）— 后端 explain 端点对 JudgeAwareClient 的接口错配已修复（此前提问路径 100% AttributeError），AI 不可用时自动回退本地兜底回答

## 安装方式

1. 保持思忆集桌面端运行
2. 打开浏览器扩展开发者模式
3. 选择“加载已解压的扩展程序”
4. 指向当前目录

## 本地接口

默认连接地址：

http://127.0.0.1:18766

桌面端会在启动时自动拉起本地桥接服务。

如果桌面端改过端口，可在侧边栏的“桌面连接”区域直接调整桥接地址并重新诊断。

## 设置页

安装扩展后，可在浏览器的扩展详情页点击“扩展程序选项”，或在侧边栏中点击“设置”。

设置页当前提供：

- 桥接地址保存与恢复默认值
- 连接测试与最近状态记录
- 上架前自检提示

## 本地测试

在当前目录执行：

- node tests/content-script.sample.test.js
- node tests/bridge-utils.sample.test.js
- node tests/background.add-word.test.js

用于快速验证页面上下文提取、桥接诊断辅助函数和划词入库 RPC 链路。

## 已知边界

- 当前优先支持 Chromium 内核浏览器
- 浏览器内置页、扩展页、部分受限页面无法读取正文
- Firefox 兼容层尚未补齐，需要后续单独适配 sidebar API
