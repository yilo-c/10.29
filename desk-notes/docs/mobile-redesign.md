# 思忆便签移动端重设计说明

> 版本：v2.1  
> 状态：PWA 方案已废弃，手机端已使用 Capacitor 新项目重写。本文档仅作设计参考。
> 日期：2026-05-14  
> 目标：把移动端从“功能集合”收束为一个日常可用、安静克制、以待办为核心的随身决策辅助工具。

---

## 1. 核心定位

### 一句话定义

**思忆便签移动端 = 待办优先的轻量行动面板，传统历法信息只作为低干扰参考。**

它不是算命 App，不替用户做决定；它也不是完整知识库，不和 Notion、系统笔记抢复杂编辑能力。它要解决的是一个更具体的场景：

> 用户打开手机，在 30 秒内知道今天要做什么、现在适合处理什么、是否需要多留意某类事项。

### 产品原则

| 原则 | 落地含义 |
|---|---|
| 待办先于参考 | 首页必须先完成记录、查看、完成、删除、筛选待办，不让参考信息压过行动。 |
| 信息克制 | 禁用“吉凶、改运、化解、预测”等强暗示词，统一使用“参考、较顺利、宜谨慎、传统认为”。 |
| 不越界 | 不主动推送命理结论，不建议用户改时间，只提供可忽略的信息。 |
| 快速可用 | 主要操作 1 次点击或 1 次手势内完成；详情、编辑、参考说明用底部 Sheet。 |
| 离线可用 | 待办、笔记、设置必须离线完整可用；天气、AI、网络参考失败时静默降级。 |

### 非目标

- 不做复杂项目管理：不做甘特图、子任务树、团队协作。
- 不做重型笔记：不做双链、数据库、复杂 Markdown、网页剪藏。
- 不做强玄学包装：不做运势评分、吉凶大字报、神秘化视觉、焦虑型通知。
- 不做多层路由：移动端保持四个主 Tab，编辑和详情都留在当前上下文。

## 2. 信息架构

### Tab 结构

```
待办       参考       笔记       设置
主入口     辅助       轻记录     偏好与数据
```

| Tab | 主要任务 | 设计优先级 |
|---|---|---|
| 待办 | 今日事项、快速新增、完成、删除、番茄钟、轻量参考 | P0 |
| 参考 | 八字、黄历、时辰、罗盘的集中查看 | P1 |
| 笔记 | 极简记录、搜索、文件夹 | P2 |
| 设置 | 个人资料、参考强度、显示、AI、数据管理 | P1 |

### 导航规则

- Tab 平级切换，不引入 `react-router`。
- 新建、编辑、详情、解释说明全部使用底部 Sheet。
- Sheet 关闭后回到原列表位置，不重置滚动。
- FAB 只在待办页和笔记页出现；键盘弹出时隐藏。
- 参考页只承载“查看”，不承载高频创建动作。

## 3. 用户关键路径

### 路径 A：打开 App 查看今天要做什么

1. 进入待办页。
2. 顶部看到日期、农历、天气。
3. 看到一行压缩的今日参考信息。
4. 下方直接是今日待办列表。
5. 用户右滑完成，左滑删除，点击进入编辑。

验收标准：首屏不需要滚动即可看到至少 2 条待办；没有待办时能看到明确的新建入口。

### 路径 B：快速新增待办

1. 点击右下角 `+`。
2. 底部 Sheet 弹出，焦点默认在标题输入框。
3. 用户输入标题。
4. 可选设置时间、分类、优先级、事项类型。
5. 点击完成后 Sheet 关闭，新事项出现在列表顶部或对应日期分组。

验收标准：只输入标题也能保存；可选项不会阻碍快速记录。

### 路径 C：查看某条待办的传统参考

1. 待办有事项类型，且参考强度为“完整”时显示“参考”入口。
2. 点击入口弹出参考 Sheet。
3. Sheet 展示与该事项类型相关的简短建议和来源说明。
4. 用户关闭后回到待办列表。

验收标准：参考信息不改变待办时间，不给出命令式建议。

### 路径 D：把 App 退化成纯待办工具

1. 进入设置。
2. 将“参考信息强度”设为“隐藏”。
3. 待办页隐藏 AlmanacStrip 和待办参考入口。
4. 参考页显示“参考信息已隐藏”，提供恢复入口。

验收标准：隐藏后核心待办、笔记、番茄钟仍完整可用。

## 4. 视觉设计系统

### 设计方向

**深色、安静、有质感，但避免神秘化。**

移动端需要更像一个随身效率工具，而不是黄历软件。视觉应偏向“低亮度工作台”：层级清楚，按钮好点，文字好读，参考信息有存在感但不抢主任务。

### 色彩 Token

```css
:root {
  --bg-primary: #0a0a12;
  --bg-secondary: #111118;
  --bg-tertiary: #191924;
  --bg-glass: rgba(255, 255, 255, 0.04);

  --text-primary: #ededf0;
  --text-secondary: #a0a0ae;
  --text-tertiary: #6b6b78;
  --text-disabled: #454552;

  --gold-primary: #c9a75c;
  --gold-muted: #8a7130;
  --gold-surface: rgba(201, 167, 92, 0.1);

  --tone-smooth: #6fb389;
  --tone-neutral: #a0a0ae;
  --tone-caution: #c9a75c;
  --danger: #e57373;

  --border-subtle: rgba(255, 255, 255, 0.06);
  --border-card: rgba(255, 255, 255, 0.08);
  --border-active: rgba(201, 167, 92, 0.28);
}
```

使用限制：

- 禁用大面积红色、绿色表达“吉凶”。
- 金色只用于选中、强调、主要 CTA，不铺满背景。
- 危险色只用于删除、清除数据等真实破坏性操作。
- 每个页面最多一个主要 CTA。

### 排版 Token

```css
font-family: -apple-system, "PingFang SC", "Noto Sans SC",
  "Microsoft YaHei", sans-serif;
```

| `--text-h1` | 20px | 600 | 1.4 | 页面标题 |

| `--text-small` | 13px | 400 | 1.5 | 辅助信息 |
| `--text-tiny` | 11px | 500 | 1.4 | 标签、脚注 |

### 间距与尺寸

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 20px;
--space-6: 24px;
--space-8: 32px;

--radius-sm: 6px;
--radius-md: 10px;
--radius-lg: 16px;
--radius-xl: 22px;

--tap-target: 44px;
--bottom-tab-height: 64px;
```

规则：

- 所有可点击区域最小 `44px`。
- 列表项最小高度 `72px`，复杂项可到 `88px`。
- 页面左右内边距 `16px`，窄屏不低于 `14px`。
- 卡片圆角不超过 `10px`，Sheet 可用 `16px`。

### 动效 Token

```css
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--duration-fast: 120ms;
--duration-normal: 220ms;
--duration-sheet: 280ms;
```

规则：

- 列表完成、删除、Sheet 弹出必须有过渡。
- 动效只表达状态变化，不做装饰性循环动画。
- 尊重 `prefers-reduced-motion`，关闭非必要位移动画。

## 5. 待办页规格

待办页是默认首页，也是移动端成败的核心。它必须在小屏幕上保持信息密度，同时让用户有“马上能做事”的感觉。

### 首屏结构

```
安全区
DateHeader
AlmanacStrip（可被设置隐藏）
CategoryChips
TodoList
PomodoroBar（有计时任务时显示）
FAB
BottomTabBar
```

### DateHeader

展示：

- 第一行：`5月14日 周四`
- 第二行：`丙午年 三月廿八`，天气可用时追加 `· 22°C 多云`

规则：

- 天气失败时整段天气静默隐藏。
- 不在这里展示“宜忌”，避免头部过重。
- 日期区域点击可打开日期选择 Sheet，用于查看其他日期待办。

### AlmanacStrip

默认折叠为一行：

```
较顺利：签约、出行、纳财 · 宜谨慎：动土、安葬
```

展开后显示：

- 较顺利事项
- 平日事项
- 宜谨慎事项
- 冲煞/方位简述
- 来源说明入口

规则：

- 参考强度为“隐藏”时不显示。
- 参考强度为“精简”时只显示折叠一行，不显示待办参考入口。
- 参考强度为“完整”时可展开，并允许待办关联参考。

### CategoryChips

```
全部 12 / 今日 5 / 工作 3 / 个人 2 / 学习 1 / 生活 1
```

规则：

- 横向滚动，隐藏滚动条。
- 默认选中“今日”；没有今日事项时选中“全部”。
- Chip 内数字只统计未完成事项。

### TodoItem

信息层级：

1. 优先级点 + 优先级文字
2. 标题
3. 时间、地点、备注摘要
4. 事项类型、参考入口、更多操作

示例：

```
● 高
季度项目汇报
14:00 · 策划部会议室
签约   参考   ···
```

交互：

- 点击：打开编辑 Sheet。
- 右滑：完成/取消完成。
- 左滑：删除，底部 Snackbar 提供 3 秒撤销。
- 长按：打开操作 Sheet，包括开始番茄钟、复制、移动分类、删除。

完成态：

- 标题使用 `text-tertiary`。
- 标题可加删除线，但不要整卡变灰到不可读。
- 完成事项默认保留在当天列表底部。

### CreateTodoSheet

字段优先级：

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| 标题 | 是 | 空 | 自动聚焦 |
| 日期 | 否 | 今天 | 可选今天、明天、自定义 |
| 时间 | 否 | 无 | 未设置时不显示占位 |
| 分类 | 否 | 当前分类 | 可改 |
| 优先级 | 否 | 中 | 高/中/低 |
| 事项类型 | 否 | 无 | 用于参考匹配 |
| 备注 | 否 | 空 | 多行输入 |

底部按钮：

- 主按钮：`保存`
- 次按钮：`取消`

验收标准：只填标题即可保存；键盘弹出时保存按钮仍可访问。

### PomodoroBar

显示条件：有正在计时或暂停的任务。

展示：

```
季度项目汇报     24:36     暂停/继续
```

规则：

- 固定在底部 Tab 上方。
- 点击打开番茄钟 Sheet。
- 计时不中断 Tab 切换。

## 6. 参考页规格

参考页是“集中查看”，不是第二个首页。它应让用户在需要时深入，不需要时不打扰。

### 页面结构

1. TodaySummary：今天的简短总结。
2. HuangliCard：黄历参考，默认展开。
3. BaziCard：八字参考，默认折叠。
4. QimenCard：时辰参考，默认折叠。
5. CompassCard：方位罗盘，默认折叠。

### TodaySummary

内容原则：

- 最多 3 行。
- 不做评分。
- 不使用“今日运势”。

示例：

```
今日参考
较适合处理签约、整理、沟通类事项。重要决定仍建议以实际条件为准。
```

### 卡片展开规则

- 每张卡片独立展开/收起。
- 展开状态在本次会话内保留。
- 卡片内必须有“来源/说明”入口。
- 计算失败只影响当前卡片，不影响其他卡片。

### 罗盘

罗盘是辅助视图，不做强引导。

规则：

- 无传感器权限时展示静态方位盘。
- 请求权限必须由用户点击触发。
- 不弹窗催促授权。
- 方位文案使用“当前朝向”“可参考方位”，不用“吉方”“凶方”。

## 7. 笔记页规格

笔记页只做“轻记录”，服务于待办之外的短内容。

### 功能边界

P0：

- 新建笔记
- 编辑笔记
- 删除笔记
- 搜索标题和正文
- 文件夹筛选

P1：

- 文件夹新增、重命名、删除
- 简易 Markdown 预览

不做：

- 多级文件夹
- 图片插入
- 表格
- 双链
- 富文本工具栏

### NoteList

列表项展示：

- 标题
- 正文摘要最多 2 行
- 更新时间
- 文件夹标签

空状态：

```
还没有笔记
点击 + 记录一点东西
```

### NoteEditorSheet

字段：

- 标题
- 正文
- 文件夹

规则：

- 自动保存草稿。
- 关闭时如果为空标题且为空正文，不创建笔记。
- Markdown 只支持最小集合：加粗、列表、引用、分割线、行内代码。

## 8. 设置页规格

设置页承载“控制感”。用户必须能清楚地知道自己打开了什么、隐藏了什么、数据在哪里。

### 分区

| 分区 | 内容 |
|---|---|
| 个人资料 | 出生日期、出生时辰、性别/偏好称谓，可跳过 |
| 参考信息强度 | 隐藏、精简、完整 |
| 显示偏好 | 主题、语言、完成事项显示 |
| AI 辅助 | 开关、API URL、模型名 |
| 数据管理 | 导出数据、导入数据、清除数据 |
| 关于 | 版本、开源协议 |

### 参考信息强度

| 强度 | 待办页 | 参考页 | 待办参考入口 |
|---|---|---|---|
| 隐藏 | 不显示参考条 | 显示关闭状态和恢复入口 | 不显示 |
| 精简 | 显示一行今日参考 | 仅黄历卡片 | 不显示 |
| 完整 | 完整可展开参考条 | 全部卡片 | 显示 |

默认值：`完整`。

## 9. 交互与状态规范

### 触控反馈

| 操作 | 视觉反馈 | 时长 |
|---|---|---:|
| 点击按钮 | `scale(0.98)` 后恢复 | 120ms |
| 点击列表项 | 背景变为 `--bg-tertiary` | 120ms |
| 长按 | 背景加深，触发操作 Sheet | 500ms |
| 左滑删除 | 露出删除操作，确认后移除 | 220ms |
| 右滑完成 | 露出完成操作，确认后变更状态 | 220ms |
| Sheet 打开 | 自底向上滑入 | 280ms |
| Snackbar | 自底部淡入，3 秒后消失 | 180ms |

### 空状态

空状态必须包含：

- 一个简短标题
- 一个下一步动作
- 不使用插画堆空间

示例：

- 待办空：`今天还没有待办` / `点击 + 添加一条`
- 搜索空：`没有找到相关内容` / `换个关键词试试`
- 参考隐藏：`参考信息已隐藏` / `可在设置中恢复`

### 加载状态

- 首次启动：列表骨架屏。
- 参考计算：卡片内骨架，不挡住其他页面。
- 天气：不显示加载态，成功才展示。
- AI：失败时隐藏 AI 区域或显示“暂不可用”，不弹全局错误。

### 错误状态

- 删除、清除数据必须可撤销或二次确认。
- 网络失败不影响离线功能。
- 单个参考模块失败不影响其他模块。
- 表单保存失败时保留用户输入。

### 可访问性

- 文本和背景对比度不低于 WCAG AA。
- 所有图标按钮需要 `aria-label`。
- 不用颜色作为唯一信息载体。
- 支持系统减少动态效果。

## 10. 文案规范

### 禁用词

```
预测、改运、消灾、化解、做法事、保佑
大吉、大凶、凶日、凶方、凶时、禁忌
命定、犯煞、刑克、镇宅、灵符、咒语、转运
```

### 替代表达

| 禁用/强暗示 | 替代 |
|---|---|
| 预测 | 参考 |
| 吉 | 较顺利 |
| 凶 | 暂不使用该概念 |
| 忌 | 宜谨慎 |
| 吉方 | 可参考方位 |
| 冲煞 | 传统认为需留意 |
| 改运 | 调整计划 |
| 命理分析 | 传统历法参考 |

### 固定句式

- `以上信息依据传统历法理论整理，仅供做决策时参考。`
- `重要事项仍建议以实际条件、专业意见和个人判断为准。`
- `传统认为此类事项宜多方确认。`
- `当前信息暂不可用，不影响待办和笔记功能。`

### UI 命名

| 场景 | 使用 | 避免 |
|---|---|---|
| 参考页标题 | 今日参考 | 今日运势 |
| 八字模块 | 八字参考 | 命理分析 |
| 时辰模块 | 时辰参考 | 奇门预测 |
| 罗盘模块 | 方位罗盘 | 风水罗盘 |
| 设置项 | 参考信息强度 | 命理显示 |
| 事项字段 | 事项类型 | 宜忌标签 |

## 11. 组件清单

- `Sheet`：Modal / Action / Info
- `Snackbar`：撤销、轻提示
- `Divider`：细分割线
- `Skeleton`：列表和卡片占位

业务组件：

- `DateHeader`
- `AlmanacStrip`
- `TodoItem`
- `CreateTodoSheet`
- `PomodoroBar`
- `ReferenceCard`

## 13. 技术约定

- 移动端使用纯 CSS + CSS custom properties，不引入 TailwindCSS。
- 不引入第三方 UI 组件库。
- 不使用嵌套路由，采用 Tab 状态切换。
- 状态优先复用 shared store 和 persist 结构。
- PWA 保持核心功能离线可用。
- 包体目标：`JS gzip < 80KB`，`CSS gzip < 10KB`。
- 所有新增交互组件需要覆盖空状态、加载状态、错误状态和窄屏状态。
