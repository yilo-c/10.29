# 小问桌宠完整设计书（GPT 设计与生成专用）

本文档是「思忆集」桌面端桌宠角色"小问"的完整设计说明。
请基于本文档为小问设计与生成全套动画素材（sprite sheet 序列帧 + 待机立绘图层）。
生成过程中必须持续遵守 §3 技术规格与 §6 质量纪律，它们来自实际生产中踩过的坑，
违反任何一条的产出都会被拒收。

---

## 1. 角色与产品背景

小问是个人 AI 助手"思忆集"的桌面常驻角色，以透明悬浮小窗（约 288×316 像素，
角色显示约 240px 高）出现在用户桌面上。她的职责：

- **视觉陪伴**：待机呼吸、眨眼、环绕特效，安静而有生命力；
- **交互反馈**：被单击/双击/拖动/连击时播放对应反应动作并冒出台词气泡；
- **情绪表达**：收到通知侧耳倾听，夜间困倦，应用启动时御剑落地报到。

使用场景决定素材特性：**角色长时间处于安静的循环待机状态**（占 90% 时间），
因此循环动作的流畅度与自然度是最高优先级；交互动作短促有表现力即可。

## 2. 角色设定（所有生成必须锁定）

```text
姓名：小问
门派：一梦江湖 · 华山派
性格：冷飒外表 · 傲娇内核 · 剑痴 · 迷糊小师妹
```

**视觉锚点（不可更改）**：
- 灰蓝色高马尾，头顶金色小熊发饰，额前碎刘海；
- 大而圆的浅蓝色眼睛，白色高光；
- 浅蓝色中式交领短袖上衣，袖口/下摆白色云纹；
- 深藏蓝百褶短裙；宝蓝色宽腰带蝴蝶结（中心白色圆珠，两端飘带）；
- 白色过膝袜（波浪袜口）+ 黑色小皮鞋；
- 黑色长剑不离身，剑柄蓝色流苏剑穗；
- 特效色：冰蓝剑意、白色云气（克制使用，绝不大面积光效）。

**画风**：日系 Q 版平涂，约 2.5 头身，干净线稿，柔和赛璐璐上色，
无写实元素，无粗黑重阴影。

**台词气质**（帮助理解每个动作应有的情绪）：
- 待机："剑在人在……呼……""华山剑法第三式……咦，第三式是什么来着？"
- 被戳："干嘛！——哦，是你啊。"
- 害羞："戳一下两下的……当心我用剑气挠你痒痒哦！"
- 被拖："喂喂，我自己会走……"
- 落地："到了——唔，落地有点歪。"

## 3. 动画素材技术规格（硬性约束）

### 3.1 输出形态：sprite sheet

每个动作输出一张横版 sprite sheet：
- 帧数 10–16 帧（见 §4 动作清单），排成一行（超过 8 帧可两行，先左后右先上后下）；
- 画幅建议 1536×1024（单行）或 1024×1536（双行），输出高清；
- **纯白背景**（或透明背景），单角色完整全身入画，不得裁切。

### 3.2 流畅度要求（重点，此前最大痛点）

此前素材每动作仅 4–7 个关键帧，播放生硬如翻页。必须做到：

1. **帧数是中间帧不是关键帧**：相邻两帧之间姿势变化小而连续
   （位移 ≤ 角色高度 5%，角度 ≤ 8°），不允许姿势跳变；
2. **循环动作首尾衔接**：第 1 帧与最后 1 帧几乎相同，保证无缝循环；
3. **所有帧比例一致**：角色大小、头身比逐帧不变；
4. **脚底锚点稳定**：站立类动作双脚始终在同一水平线，不得逐帧漂移；
5. **帧序可读**：动作有清晰的起势-过程-收势节奏，不要匀速平铺。

### 3.3 一致性要求

1. 每个动作只出一张图（同图内一致性远好于跨图）；
2. 所有动作在同一会话内连续生成，保持画风统一；
3. 每次生成附上三视图设定稿作结构参考；
4. 脸型、发型、服饰、黑剑、比例与设定锁完全一致，禁止漂移。

### 3.4 画面洁净度要求（此前黑点/黑边教训）

1. 严禁黑底——抠像时黑底会污染角色深色部位（藏蓝裙、黑剑、瞳孔）；
2. 严禁：文字、编号、格子边框、对白气泡、背景场景、地面阴影、水印、动感线；
3. 角色边缘干净，无白色毛边、无半透明光晕残留；
4. 环绕类特效（水珠、云气）除非动作明确要求，一律不画——由程序渲染。

## 4. 全量动作清单（共 11 个动作 + 2 张立绘）

帧数已按"专业流畅度"标准上调（旧版 4–7 帧 → 现 10–16 帧）。

### P0 循环常驻类（最高优先级，决定 90% 时间观感）

#### A1. idle 待机（12 帧，循环）
抱剑或拄剑放松站立，逐帧脚本：
①起始站姿 → ②③④吸气微起（胸口/肩部 1–2px 级上抬，衣摆微张）→
⑤⑥呼气回落 → ⑦眨眼（双眼闭合 1 帧）→ ⑧睁眼 →
⑨⑩马尾与衣摆被微风吹动一次 → ⑪⑫回到与 ① 几乎相同的站姿。
情绪：安静、克制、偶尔迷糊。

#### A2. notice 侧耳倾听（10 帧，循环）
①站姿 → ②忽然侧头，一手拢在耳边 → ③④倾听（眼睛睁大，马尾一抖）→
⑤⑥保持倾听微点头 → ⑦⑧缓缓放松 → ⑨⑩回到与 ① 相同的站姿。

#### A3. chatOpen 悬空打坐（10 帧，循环）
盘腿悬空打坐，黑剑横放膝上：
①起始坐姿 → ②③④吸气上浮 2–3px → ⑤⑥⑦呼气下沉 →
⑧双手结印微光一闪（极克制）→ ⑨⑩回到 ①。
情绪：端庄但可爱，闭眼调息。

#### A4. sleepy 困倦（10 帧，循环）
抱剑打瞌睡：①抱剑站姿眼皮半耷 → ②③头缓缓下垂 → ④猛然一醒（头弹回）→
⑤揉眼 → ⑥⑦又犯困头再垂 → ⑧⑨再惊醒 → ⑩回到 ①。
情绪：困但不失可爱，不要夸张流口水。

#### A5. dragFly 御剑飞行（12 帧，循环）
侧身踩黑剑向右前飞行：
①起始飞行姿态 → ②-⑥上下小幅起伏（正弦，±2–3px）马尾衣摆持续向后飘 →
⑦-⑪反方向起伏回到原位 → ⑫与 ① 相同。
剑下一缕克制的蓝白云气（可以画，这是动作本体）。

### P1 交互反馈类

#### B1. clickDefend 受惊戒备（10 帧，不循环）
①静止 → ②③受惊缩肩、反手握住剑鞘（头顶一个小惊起符号，不要文字）→
④⑤半拔剑戒备 → ⑥⑦看清来人愣住 → ⑧⑨傲娇收剑别过脸 → ⑩放松站姿。
情绪曲线：惊 → 戒备 → 安心 + 傲娇。

#### B2. shy 害羞捂脸（10 帧，不循环）
①被戳愣住 → ②③抬袖 → ④⑤宽袖遮住半脸只露一只眼偷看，脸颊泛粉 →
⑥⑦头顶冒出细小的害羞符号（无爱心无文字）→ ⑧从袖口瞪一眼 →
⑨缩回袖子 → ⑩维持遮脸站姿收尾。

#### B3. land 急停落地（10 帧，不循环）
①下落末段（剑在脚下）→ ②③跳离剑 → ④落地微蹲踉跄 →
⑤⑥甩头稳住 → ⑦⑧整理衣摆 → ⑨抱起剑 → ⑩站定，表情微迷糊。

#### B4. startup 启动报到（10 帧，不循环）
①御剑从上方入画 → ②③下落 → ④落地微蹲（少量白色云气）→
⑤起身 → ⑥拍衣摆 → ⑦⑧抱剑扬下巴 → ⑨⑩元气站姿收尾。
情绪：元气报到，傲娇自信。

### P2 表演类（剑招，最后做）

#### C1. combo3 疏狂剑意（14 帧，不循环）
①②横剑起手 pose → ③-⑥向前一记轻快横斩（剑锋一线冰蓝剑意，克制）→
⑦⑧剑势带起衣摆马尾 → ⑨-⑫收剑背手 → ⑬⑭站定。

#### C2. combo5 剑并箫（16 帧，不循环）
三连招：①-⑤横劈 → ⑥-⑩上挑（冰蓝剑意沿剑轨小范围出现）→
⑪-⑮利落收鞘（鞘响的瞬间 1 帧顿挫）→ ⑯马尾甩落站定，帅气收尾。
节奏要有明显的轻重顿挫，不要每帧平均用力。

### D. 待机立绘图层（2 张，程序化渲染专用）

除序列帧外，待机状态还会用"立绘 + 程序化动画"渲染（呼吸浮动、马尾摆动、
眨眼由程序驱动），需要两张配套立绘：

**D1. 待机基底立绘**：
- 姿态：元气持剑站姿——右手握黑剑（剑尖朝下置于身体一侧外缘），
  左手握拳抬在胸前，身体微微前倾，双眼睁大看向镜头，明朗元气的笑容；
- 纯白背景，完整全身居中，角色高度占画幅 80%，高清 ≥1024px；
- 不要任何动感线/雾气/水珠/光效（环绕特效由程序渲染）；
- 眼睛必须完全睁开且不被头发遮挡（眨眼由 D2 图层实现）。

**D2. 闭眼版立绘**：
- 与 D1 完全一致（姿势/服装/颜色/构图/线条），仅把双眼改为自然闭合
  （弯弯的闭眼睫毛线），表情变为开心闭眼笑；
- 与 D1 相同分辨率。

## 5. 生成顺序建议

1. 先出 D1+D2（立绘），确认角色画风与设定锁无误——这是后续所有图的基准；
2. 再出 P0 五个循环动作（idle → dragFly → chatOpen → notice → sleepy）；
3. 然后 P1 四个交互动作；
4. 最后 P2 两个剑招。
每出一张先自查（§6）再继续，不要批量生成后集中返工。

## 6. 质量纪律与验收

### 6.1 生成纪律

1. 同一会话内连续生成所有图，防止画风漂移；
2. 每次生成必须附三视图设定稿 + §2 设定锁原文；
3. 每张图生成后 GPT 自查并回答：
   帧数是否正确 / 是否有文字编号气泡 / 相邻帧是否连续无跳变 /
   循环动作首尾是否衔接 / 比例与脚底锚点是否一致 / 是否有黑底或阴影残留；
4. 任一项不合格：整张重 roll，禁止挑帧凑合。

### 6.2 验收清单（逐张）

- [ ] 帧数与 §4 一致，无缺帧无重复帧
- [ ] 纯白底/透明底，无黑底、无地面阴影
- [ ] 无文字、编号、边框、对白框、水印、多余特效
- [ ] 角色脸型/发型/服饰/黑剑与设定锁一致
- [ ] 相邻帧连续（位移 ≤5%、角度 ≤8°），无跳脸无比例突变
- [ ] 循环动作首尾帧可无缝衔接
- [ ] 脚底锚点逐帧稳定（站立类）

### 6.3 历史缺陷黑名单（曾发生，严禁复发）

| 缺陷 | 成因 | 预防 |
| --- | --- | --- |
| 帧太少，播放如翻页 | 每动作只给 4–7 关键帧 | 帧数下限 10，且必须是连续中间帧 |
| 面部黑点/下半身消失 | 黑底素材抠像污染深色部位 | 纯白底，禁黑底 |
| 图与图之间形象不一致 | 跨调用画风漂移 | 同会话 + 设定锁 + 三视图参考 |
| 编号/对白框残留 | 分镜图直接裁切 | 只要 sprite sheet，禁分镜排版 |
| 动作僵硬 | 关键帧无补间 | §3.2 连续性与首尾衔接要求 |
