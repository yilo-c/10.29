# 小问待机升级设计 v2（图层 + 程序化驱动）

本设计基于用户确认的方向：以「微信图片_7 持剑元气站姿」为待机姿态蓝本，
修复眨眼白洞问题，新增水珠环绕特效与待机微动优化。

**分工**：用户负责按 §2 生成两张图；程序侧效果（§3）全部由渲染器实现，
不需要为特效生图。图到位后按 §4 实施。

## 3. 程序化效果设计（图到位后由渲染器实现）

### 3.1 眨眼 v2：闭眼图层交叉淡化

- 删除现有肤色眼皮矩形绘制（白洞根因）；
- 闭眼图层与身体图层同尺寸对齐加载；
- 眨眼 = 以 `globalAlpha = lid(0→1→0)` 叠加闭眼图层，全程 130ms；
- 间隔 2.2–5.5s 随机；15% 概率触发「连眨两次」增加生动感；
- 闭眼图层加载失败时优雅降级：不眨眼（宁缺毋滥，不再出现白洞）。

### 3.2 水珠环绕（新增，呼应冰蓝剑意设定）

- **数量/外观**：7±2 颗冰蓝半透明水珠，径向渐变（白蓝亮心 → 透明边缘），
  前半球水珠带高光点与短尾迹；
- **轨道**：绕躯干中心的斜椭圆（长轴 ≈ 角色宽 95%，短轴 ≈ 25%，
  轨道平面微倾 10°），各水珠速度略有差异（6–9s/圈），纵向带微小正弦漂移；
- **遮挡关系**：按轨道相位分前后半球——后半球画在身体图层**之前**
  （稍小、稍暗），前半球画在身体**之后**（稍大、稍亮），
  形成真实的绕体环绕感；
- **节奏调度**：淡入 1s → 环绕 8–12s → 淡出 1.5s → 停歇 18–30s 随机循环；
  台词气泡出现时水珠加速淡出，避免信息干扰；
- **交互呼应**：dragFly/连击等动作触发时水珠立即收敛（复用现有粒子淡出）。

### 3.3 微摆（新增）

- 身体绕脚底枢轴 ±0.5° 缓慢摇摆，周期 6–9s 随机，
  与呼吸（3.2s）相位独立，避免机械感；
- 马尾摆动的激励源叠加微摆角速度，发丝响应更自然。

### 3.4 剑意微光（新增）

- 每 8–15s 在剑身标定段随机生成 2–3 颗冰蓝光点，
  沿剑身向上漂移 ~30px 后淡出（寿命 800ms）；
- 光点走现有粒子系统（`spawnSwordSpark` 的冰蓝变体），不新增渲染路径；
- 剑身标定段在图层重切时通过暗色竖直簇自动定位，写入 manifest。

### 3.5 待机行为调度器

三档行为按权重轮转，让待机"有节目"但不吵闹：

| 档位 | 内容 | 时长 | 权重 |
| --- | --- | --- | --- |
| 常规待机 | 呼吸 + 马尾 + 眨眼 + 微摆 | 15–30s | 60% |
| 水珠环绕 | 叠加 3.2 | 10–14s | 28% |
| 剑意微光 | 叠加 3.4（可与常规同出） | 事件型 | 12% |

mood 事件（thinking/alert 等）立即打断当前档位切回常规待机。
