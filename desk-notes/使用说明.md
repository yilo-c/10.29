# 思忆便签 — 使用说明

---

## 一、界面总览

```
┌──────────────────────────────────────────────┐
│  [─] [×]        便签        [📌] [🔒] [◐]   │ ← 标题栏
├────┬─────────────────────────────────────────┤
│    │ 🔍 搜索待办...                          │ ← 搜索栏
│ 全 │ ┌─ 新建待办输入框 ──┐                   │ ← 新增待办
│ 部 │ └───────────────────┘                   │
│    │ ○ 完成项目演示 PPT 制作    14:30  ✕     │ ← 待办列表
│    │ ✓ 整理本周工作周报        昨日   ✕     │
│ 分 │ ───── 2 项已完成 ─── [清除] ─────       │
│ 类 │ ✓ 整理本周工作周报                       │
│ 栏 │ ✓ 更新项目进度看板                       │
│    │                                          │
│    │                                          │
├────┴─────────────────────────────────────────┤
│       [+ 新建文本]   [✓ 新建待办]             │ ← 底部工具栏
└──────────────────────────────────────────────┘
                                          ║  ← 宽度拖拽手柄
```

---

## 二、功能详解

### 1. 主面板

半透明亚克力毛玻璃面板，可直接看到桌面壁纸。

#### 标题栏操作区

| 按钮 | 名称 | 功能 |
|------|------|------|
| ─ | 最小化 | （仅桌面版）将主窗口最小化到任务栏 |
| ✕ | 关闭 | （仅桌面版）关闭整个应用 |
| 便签 | 标题文字 | 拖动标题栏可移动面板位置（浏览器模式） |
| 📌 | 置顶 | 面板始终保持在所有窗口最前方，再次点击取消 |
| 🔒 | 锁定 | 面板不可拖动移动，再次点击解锁 |
| ◐ | 透明度 | 弹出滑块调节面板透明程度（15%~100%） |

#### 底部工具栏

| 按钮 | 功能 |
|------|------|
| [+ 新建文本] | 创建一张文本便签浮动窗口，可在上面任意书写 |
| [✓ 新建待办] | 在面板内添加一条待办事项（搜索栏下方出现输入框） |

---

### 2. 分类管理（左侧窄栏）

竖排显示所有分类按钮。**默认分类：** 个人 · 重要 · 读书 · 日程 · 灵感 · 收藏 · 生日

| 操作 | 说明 |
|------|------|
| 点击网格图标 | 显示所有分类的待办 |
| 点击分类按钮 | 筛选显示该分类下的待办 |
| **按住分类拖出** | 创建该分类的独立浮动窗口，窗口中包含该分类下所有未完成的待办 |
| 悬停分类右上角 ✕ | 删除该分类（至少保留一个分类） |
| 点击底部 ➕ | 弹出输入框，填写分类名称后按 Enter 或点"添加"确认 |

---

### 3. 待办管理（主区域）

#### 搜索栏

- 输入关键词，实时筛选待办列表
- 右侧 ✕ 按钮一键清空搜索

#### 添加待办

- 点击底部工具栏「[✓ 新建待办]」，搜索栏下方出现输入框
- 输入内容，按 `Enter` 或点击 ➕ 添加
- 输入框失焦也会自动提交

#### 待办列表

| 元素 | 说明 |
|------|------|
| ○ 空心圆 | 任务未完成，点击后标记为已完成（移到已完成区） |
| ✓ 勾选圆 | 任务已完成，点击恢复为未完成 |
| 文字内容 | 待办描述 |
| 时间戳 | 创建时间（时:分） |
| ✕ | 鼠标悬停时显示，点击删除该待办 |
| **按住待办拖出** | 将待办拖出为独立浮动窗口 |

#### 已完成区

- 分隔线下方显示「N 项已完成」
- 「清除」按钮一键删除所有已完成待办

---

### 4. 浮动窗口（便签）

浮动窗口有两种类型：**文本便签** 和 **待办清单**，每个窗口都包含以下功能：

#### 标题栏

| 按钮 | 名称 | 功能 |
|------|------|------|
| ─ | 最小化 | （仅桌面独立窗口模式）最小化该窗口到任务栏 |
| ✕ | 关闭窗口 | （仅桌面独立窗口模式）关闭该窗口 |
| ▼ / ▶ | 折叠 / 展开 | 点击折叠或展开便签内容区 |
| 标题文字 | 编辑标题 | **双击标题**进入编辑模式，修改后按 Enter 或失焦确认 |
| 📌 | 置顶 | 该窗口始终处于最前方，置顶时边框显示蓝色 |
| 🔒 | 锁定 | 窗口不可拖动移动 |
| ◐ | 透明度 | 弹出滑块调节该窗口的单独透明程度 |
| ✕ | 关闭/删除 | 浏览器模式删除便签；桌面版关闭该窗口 |

#### 文本便签

- 全屏可编辑文本区域，输入任意文字内容
- 窗口拉大时，文本区域自动填充可用空间
- 内容过多时自动出现滚动条

#### 待办清单便签

- 与主面板相同的勾选 / 删除操作
- 底部「+ 新增」输入框，按 Enter 添加待办

#### 拖动与缩放

| 操作 | 说明 |
|------|------|
| 拖动标题栏 | 移动浮动窗口（锁定状态下不可拖动） |
| 右下角 ↙ 手柄 | 拖拽缩放窗口大小（最小 180×100） |

---

## 三、运行模式

| 模式 | 说明 |
|------|------|
| **浏览器模式** | 所有浮动便签渲染在主页面内，面板可自由拖动 |
| **桌面独立窗口模式** | 面板全屏显示，每个浮动便签变为独立 OS 窗口，可像普通窗口一样最小化、关闭、拖动、缩放 |

---

## 四、键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Enter | 确认输入（新建待办、编辑标题、新建分类等） |
| Esc | 关闭应用（桌面版） |
| F5 | 刷新窗口（桌面版开发用） |

---

## 五、数据存储

- 所有数据保存在浏览器本地存储（localStorage），关闭页面后不丢失
- 桌面版多个窗口共享同一份数据

## 六、常见操作速查

| 我想... | 怎么做 |
|---------|--------|
| 写一段文字备忘 | 底部工具栏 →「新建文本」 |
| 记一个待办事项 | 底部工具栏 →「新建待办」→ 输入内容 → Enter |
| 完成了一项任务 | 点击待办左侧的 ○ 空心圆 |
| 删除一条待办 | 鼠标悬停待办 → 点击右侧 ✕ |
| 让面板透一点 / 不透明 | 标题栏 → ◐ 按钮 → 拖动滑块 |
| 把面板固定在桌面不让动 | 标题栏 → 🔒 按钮 |
| 把面板保持在最前 | 标题栏 → 📌 按钮 |
| 只看某个分类的待办 | 左侧分类栏 → 点击对应彩色按钮 |
| 添加一个新分类 | 分类栏底部 → ➕ → 输入名称 → 添加 |
| 把待办单独拖出来 | 按住待办文字 → 拖出 → 松开 |
| 把整个分类拖出来 | 按住左侧分类按钮 → 拖出 → 松开 |
| 调大面板宽度 | 面板右侧边缘 → 拖拽手柄（桌面版） |
| 便签内容太多折叠起来 | 浮动窗口标题栏 → ▼ 按钮 |
