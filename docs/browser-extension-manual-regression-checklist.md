# 浏览器扩展手工回归清单

适用范围：当前思忆集浏览器助手上架前的本地手工验收。

目标：确认扩展能正常加载、能连通桌面端桥接、能在三类典型页面完成总结与沉淀。

## 回归前置

- 已运行桌面端应用，默认桥接端口为 18765。
- 已在浏览器开启开发者模式。
- 已加载目录 browser-extension/siyi-browser-assistant。
- 若桌面端改过端口，先在扩展设置页里改为实际地址。

## 一、基础安装与设置

- [ ] 打开 Chrome 或 Edge 的扩展管理页。
- [ ] 选择“加载已解压的扩展程序”，指向 browser-extension/siyi-browser-assistant。
- [ ] 扩展图标、名称、版本显示正常，版本应为 0.3.0。
- [ ] 进入扩展详情页，能打开“扩展程序选项”。
- [ ] 设置页能显示桥接地址输入框、测试连接按钮、最近连接记录。
- [ ] 点击“恢复默认”后，桥接地址变回 http://127.0.0.1:18765。

预期结果：扩展安装无报错，设置页可用，无空白页或脚本报错。

## 二、桌面桥接连接检查

- [ ] 保持桌面端运行，进入扩展设置页，点击“测试连接”。
- [ ] 状态显示“桌面端已连接”或等价成功文案。
- [ ] 最近连接记录新增一条成功记录。
- [ ] 打开侧边栏，顶部状态显示已连接。
- [ ] 侧边栏“桌面连接”区域能看到最近检查时间。

预期结果：桥接地址连通，状态文案明确，不出现 Failed to fetch 这类原始错误。

## 三、异常恢复检查

- [ ] 临时关闭桌面端，再次点击设置页“测试连接”。
- [ ] 状态应显示“桌面端未启动”或“桌面端响应超时”等可理解提示。
- [ ] 最近连接记录新增失败记录。
- [ ] 重新启动桌面端后再次测试，状态恢复成功。
- [ ] 如把地址改成 localhost:18765 或 127.0.0.1:18765，至少一项可自动回退成功。

预期结果：用户能看懂失败原因和恢复路径，不需要自行理解网络错误。

## 四、文章页回归

建议页面：普通博客文章、项目文档文章、新闻正文页。

- [ ] 打开一篇普通文章页。
- [ ] 点击扩展图标或侧边栏入口，侧边栏成功打开。
- [ ] “当前页面”区域显示标题、URL、内容类型、主提取节点。
- [ ] 点击“总结当前页面”，能返回摘要、关键点、建议动作。
- [ ] 点击“存到收件箱”，桌面端成功收件。
- [ ] 点击“转成笔记”，桌面端成功生成笔记。

预期结果：内容类型通常识别为 article 或 news_page，沉淀动作均可成功。

## 五、视频页回归

建议页面：B 站视频详情页。

- [ ] 打开一个视频详情页。
- [ ] 侧边栏能识别为 video_page，或 UI 中显示“视频页”。
- [ ] 点击“总结当前页面”，返回内容包含视频类建议动作。
- [ ] 推荐动作优先项应更偏向“收件箱”或“生成任务”。
- [ ] 若页面有选中文本，点击“总结选中内容”也能成功。

预期结果：视频页不会退化成完全无差异的普通文章摘要。

## 六、文档页回归

建议页面：在线文档、文库、长篇规范页。

- [ ] 打开一个文档页。
- [ ] 侧边栏能识别为 document_page，或 UI 中显示“文档页”。
- [ ] 点击“总结当前页面”，返回内容偏结构化条目和规则摘要。
- [ ] 推荐动作优先项应更偏向“转成笔记”。
- [ ] 点击“转成笔记”后，桌面端笔记内容包含摘要、关键点、建议动作。

预期结果：文档页的总结与推荐动作和文章页、视频页有明显差异。

## 七、受限页与边界检查

- [ ] 打开浏览器内置页，例如 chrome://extensions。
- [ ] 侧边栏应给出“当前页面不允许注入扩展脚本”或等价提示。
- [ ] 不应出现空白页、无限加载或未处理异常。

预期结果：受限页失败可理解，且不会影响后续切回普通网页继续使用。

## 八、上架前最小通过标准

- [ ] 基础安装与设置全部通过。
- [ ] 桥接连接检查全部通过。
- [ ] 异常恢复检查全部通过。
- [ ] 文章页、视频页、文档页三类页面各至少通过 1 次。
- [ ] 受限页边界检查通过。

如果以上任一项失败，不建议直接上架。
