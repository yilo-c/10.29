# 微信聊天记录导出与导入指南

> 个人知识体系 M1 配套文档（2026-08-17）
> 目标：把微信聊天记录从手机/电脑导出为本地文件，再导入思忆集，构建
> 「可搜索记忆 + 个人画像 + 时间线回顾」闭环。

---

## 一、为什么需要导出工具

微信官方**不支持**直接导出聊天记录。需要用第三方工具解密本地数据库后导出。
本指南覆盖三种主流方式，按推荐顺序排列。

> ⚠️ **隐私说明**：导出的记录默认标记为「敏感」（sensitive），仅保存在
> 本机 `data/raw_items.db`，不会上传云端。当前版本不启用云同步过滤（隐私
> 机制待本地 AI 部署完成后实现），敏感标记是未来路由的前提。

---

## 二、方法 1：WeChatMsg（Windows，推荐）

开源工具，社区活跃，支持解密 + 导出多种格式。

1. **下载**：GitHub 搜 `WeChatMsg`（原留痕的前身），Release 下载
   `WeChatMsg-x.x.x-win32-x64.zip`。
2. **运行**：解压后运行 `WeChatMsg.exe`。首次运行会自动检测微信版本并
   提示「备份数据库」（需本机已登录微信 PC 版）。
3. **导出**：
   - 选择聊天对象（单人/群聊均可多选）；
   - 导出格式选 **txt**（或 csv）；
   - 点击导出，得到 `xxx.txt` 文件。
4. **格式要求**（思忆集能识别的 txt 行格式）：
   ```
   2024-01-01 10:00:00 张三: 周末一起去爬山吗？
   2024-01-01 10:05:00 我: 好啊，我喜欢爬山
   ```
   - 每行 `时间 发送人: 内容`；
   - 「我」会被识别为用户本人；
   - 系统消息（撤回/拍一拍/加好友/通话）自动过滤。

## 三、方法 2：留痕 / WxBackup（Windows）

与 WeChatMsg 同源的备份工具，界面更图形化。

1. 下载运行后同样要求本机微信已登录；
2. 选择备份聊天记录 → 导出为 txt / html / csv；
3. 导入思忆集时选择导出的 txt 或 csv 文件即可。

## 四、方法 3：手动复制（iOS / Android，无需工具）

适合少量重要对话，隐私最安全（不经过第三方工具）。

1. 在微信对话中**长按某条消息 → 多选 → 逐条勾选 → 合并转发/复制**；
2. iOS 可把复制的内容粘贴到备忘录再导出为 txt；
3. 整理成标准格式后保存为 `.txt` / `.md` 文件：
   ```
   **张三**: 周末一起去爬山吗？
   **我**: 好啊，我喜欢爬山
   ```
   （`**名字**: 内容` 是思忆集通用的 AI 对话 Markdown 格式，微信也兼容）

## 五、CSV 格式（可选）

带表头的 csv 也可直接导入，支持中英文列名：

| 中文明 | 英文列 |
|--------|--------|
| 时间 / 日期 | time / timestamp / date |
| 发送人 / 昵称 | sender / user / name / nickname |
| 内容 / 消息 | content / message / msg |

## 六、导入步骤

1. 打开思忆集前端 → 侧边栏「个人知识体系」→ **信息导入** Tab；
2. 点击「选择聊天记录文件导入」，选择导出的 txt / csv 文件；
3. 导入结果会显示：对话数 / 信息条目数（每条消息一条 raw item）；
4. 切到 **个人画像** Tab → 点「从导入内容提取画像」，自动提取：
   - 联系人（发送人去重，过滤系统账号）；
   - 兴趣/关注主题（AI 提取，失败时规则兜底）；
   - 当前焦点。
5. 切到 **信息库** Tab 可查看所有条目与敏感度标记，手动调整（标为普通/敏感）。

## 七、常见问题

| 问题 | 处理 |
|------|------|
| 导出文件导入后 raw_items_stored=0 | 格式不被识别；检查是否每行含 `时间 发送人: 内容` 结构 |
| 导入报「文件不存在」 | 确认前端能访问该路径（Electron 模式下文件选择器返回真实路径） |
| 想批量导入 | 用「数据管理」的目录导入（data.import_chat_folder），一次导入一个目录 |
| 重复导入 | 自动按内容哈希去重，重复导入 raw_items_stored=0 |

## 八、隐私与后续路线

- 当前：所有记录仅存本机，敏感度标记已生效（微信默认 sensitive）；
- 后续：本地 AI 能力足够后，启用「本地优先路由 / 同步敏感度过滤 /
  检索敏感度过滤」，sensitive 内容将不出本机——架构已预留（sensitivity
  字段 + personal.raw_items.set_sensitivity 手动调整入口）。
