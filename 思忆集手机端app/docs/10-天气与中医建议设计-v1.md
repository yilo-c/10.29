### WeatherCard 组件设计

```tsx
interface WeatherCardProps {
  city?: string           // 来自 userProfile.city
  onShare?: () => void    // 分享建议
}
```

**数据流**：

```
useEffect on mount
  → fetchWeather(city)
  → WeatherData
  → 渲染

5分钟轮询（可选）
  → setInterval 检查缓存是否过期
  → 过期则重新 fetch
```

**状态管理**：

| 状态 | 值 | 处理 |
|------|-----|------|
| loading | 首次加载中 | 骨架屏（灰色圆角块） |
| error | 网络失败无缓存 | "天气数据暂不可用" |
| error + cache | 有缓存 | 显示缓存数据 + "数据可能延迟"提示 |
| success | 正常 | 显示完整天气卡片 |
| 权限/定位失败 | 未设置城市 | "在设置中填写所在城市以查看天气" |

**天气 emoji 映射**（已有 `weather.ts`）：

```
113(晴) → ☀️    116(多云) → ⛅   119(阴) → ☁️
176(阵雨) → 🌦️  200(雷阵雨) → ⛈️  雾 → 🌫️
```

## 3. TcmEngine — 中医养生建议引擎

### 定位

纯规则引擎（无 AI 依赖），基于天气 + 季节 + 八字五行给出养生建议。

### 规则设计

```typescript
interface TcmAdvice {
  /** 核心建议（10-20字） */
  summary: string
  /** 饮食建议 */
  diet?: string
  /** 生活作息 */
  lifestyle?: string
  /** 穴位按摩（可选） */
  acupoint?: string
}

function getTcmAdvice(
  weather: WeatherData | null,
  date: Date,
  bazi: BaziProfile | null,
): TcmAdvice
```

**规则优先级**：天气 > 季节 > 八字

#### 天气维度

| 条件 | 建议 |
|------|------|
| temp >= 35 | 暑热难耐，注意防暑降温，多饮绿豆汤、酸梅汤 |
| 30 <= temp < 35 | 天气炎热，适当补充水分，避免长时间暴晒 |
| humidity >= 80 | 湿气较重，建议食用薏米、赤小豆、冬瓜祛湿 |
| humidity <= 30 | 气候干燥，多食梨、银耳、百合等润燥 |
| condition 包含"雨" | 雨天湿寒，注意关节保暖，可饮姜茶驱寒 |
| temp <= 5 | 寒气较重，注意保暖，宜进食温热食物 |
| 5 < temp <= 15 | 气温偏凉，及时增减衣物，预防感冒 |

#### 季节维度

| 季节 | 五脏 | 原则 | 建议 |
|------|------|------|------|
| 春（3-5月） | 养肝 | 疏肝理气 | 多食绿色蔬菜，早睡早起，适当运动 |
| 夏（6-8月） | 养心 | 清热养心 | 午休养心，避免大汗，多食苦味食物 |
| 秋（9-11月） | 养肺 | 润燥养肺 | 多食白色食物（梨、银耳），早卧早起 |
| 冬（12-2月） | 养肾 | 藏精温补 | 早卧晚起，适当进补，注意保暖 |

#### 八字维度（有出生信息时）

| 五行状况 | 建议 |
|---------|------|
| 木弱/缺木 | 多与自然接触，养绿植，食用绿色蔬菜 |
| 火弱/缺火 | 多晒太阳，适量运动，食用红色食物 |
| 土弱/缺土 | 规律作息，稳定居所，食用黄色食物 |
| 金弱/缺金 | 呼吸练习，多食白色食物，佩戴金属饰品 |
| 水弱/缺水 | 多饮水，游泳或泡澡，食用黑色食物 |

### 组合策略

多条规则同时命中时，最多返回 3 条建议，按以下优先级降序：
1. 极端天气（高温/严寒/暴雨）
2. 季节核心原则
3. 八字五行不足
4. 湿度异常

## 4. 简报 — 天气与中医建议集成

### 位置

在 TodoView 简报卡片内，新增建议区域：

```
┌── 今日简报 ──────────────────────┐
│ 今日待办 5 项    逾期 2 项        │
│ 进度 ▰▰▰▰▰▰▰▰▰░░ 80%            │
│ 连续完成 7 天                     │
│                                   │
│ ☀️ 28°C 北京 · 晴                 │ ← 天气一行
│ 💚 今日养生：天气炎热，注意防暑    │ ← 中医建议
│ 📋 优先处理：合同评审 → 买礼物    │ ← 建议
│                                   │
│ [+ 快速添加今日待办]              │
└──────────────────────────────────┘
```

### 实现方式

简报组件 `TodoBriefingCard` 增加：

```tsx
// 在现有 data 计算后增加：
const [weather, setWeather] = useState<WeatherData | null>(null)

useEffect(() => {
  const city = userProfile?.city
  fetchWeather(city).then(setWeather).catch(() => {})
}, [])

const tcmAdvice = useMemo(() => {
  return getTcmAdvice(weather, new Date(), bazi)
}, [weather, bazi])

const shareText = useMemo(() => {
  // 组合简报 + 天气 + 中医 + 待办为可分享文本
  return buildShareText(data, weather, tcmAdvice, ...)
}, [data, weather, tcmAdvice])
```

### 分享建议

简报或建议区域下方"分享"按钮：

```tsx
<button onClick={handleShare}>
  分享今日建议
</button>
```

生成的分享文本格式：

```
📋 思忆便签 · 今日简报
━━━━━━━━━━━━━━━━
📅 5月16日 周五 · 农历四月初一

📌 今日待办 5 项 | 逾期 2 项
📊 完成进度 70%

☀️ 北京 28°C 晴
💚 养生：天气炎热，注意防暑
🔮 宜签约·出行·忌动土

💪 今日待办：
  ☐ 合同评审 高
  ☐ 买礼物 中
  ...

━━━━━━━━━━━━━━━━
来自 思忆便签
```

实现：

```tsx
const handleShare = async () => {
  const text = buildShareText(data, weather, tcmAdvice, todos)
  if (navigator.share) {
    await navigator.share({ title: '思忆便签 · 今日简报', text })
  } else {
    await navigator.clipboard.writeText(text)
  }
}
```
