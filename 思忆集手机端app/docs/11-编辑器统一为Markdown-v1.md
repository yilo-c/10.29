# 思忆便签 · 编辑器统一为 Markdown

> 目标：消除"纯文本 / Markdown"概念，所有笔记统一为所见即所得编辑体验
> 关联文档：[8-笔记编辑功能升级-v1.md](./8-笔记编辑功能升级-v1.md)

---

## 1. 现状问题

当前编辑器有两个模式，用户必须选择"纯文本"或"Markdown"：

```
底部栏: [200 字符 12 词] [ # 纯文本 ] [分屏]
                              ↑ 这个切换
```

对非技术用户来说，这两个概念都没有意义：
- **纯文本** — 没格式很基础，但工具栏插入了 Markdown 符号后看不懂
- **Markdown** — 需要学习 `#` `*` 语法才能用，有"预览"按钮暗示它不直观

结果是两种体验都很差：纯文本用户被工具栏符号困扰，Markdown 用户被额外步骤困扰。

---

## 2. 方案：统一为 Markdown 存储，隐藏 Markdown 概念

**核心原则：Markdown 是存储格式，不是用户可见的模式。**

```
之前:    纯文本  ← 用户二选一 →  Markdown
                                ↓
之后:    编辑器（底层 Markdown）
         ├── 工具栏按钮直接出效果
         ├── 分屏预览始终可用
         └── 用户不需要知道"Markdown"这个词
```

### 存储

所有笔记统一 `editMode = 'markdown'`。已有 `'richtext'` 笔记不需迁移——纯文本就是合法的 Markdown，显示不变。

### 编辑器 UI

```
┌──────────────────────────────────────┐
│  标题                                │
├──────────────────────────────────────┤
│  [B] [I] [H1] [H2] [≡] [☐] [❝] [—] │  ← 始终显示
├──────────────────────────────────────┤
│  内容区域（分屏/预览/编辑）            │
├──────────────────────────────────────┤
│  200 字符 · 12 词  已保存  [分屏]     │  ← 无模式切换
└──────────────────────────────────────┘
```

- 格式工具栏始终显示（不再依赖模式）
- 分屏/预览按钮始终可用（不再判断 `isMd`）
- 删除 `# 纯文本 / # Markdown` 切换按钮
- 删除"保存中..."状态指示（用户不需要知道，自动保存静默执行）

### 笔记列表卡片

```
之前:  [#] 5 分钟前     ← # 表示 Markdown 模式
之后:  5 分钟前         ← 无指示，所有笔记都是 Markdown
```

卡片外观不变，去掉 `#` 标识。

## 4. 边界情况

| 情况 | 处理 |
|------|------|
| 已有 `richtext` 笔记 | 显示不变，纯文本是合法 Markdown |
| 用户不点工具栏，只打字 | 存为 Markdown，纯内容 = 纯文本效果 |
| 用户打了 `# 标题` 自己 | MarkdownPreview 自动渲染，预览可见 |
| 打字中出现 `**` | 分屏模式可见渲染效果（问号、未闭合不渲染） |
| 导出/分享 | 内容仍是 Markdown，其他 app 兼容 |

---

## 5. 不做的事

| 不做 | 原因 |
|------|------|
| 不做富文本编辑器（contentEditable） | 实现复杂，Markdown 对开发者兼容性好，工具栏 + 分屏已是轻量 WYSIWYG |
| 不迁移存量数据 | 纯文本 = 合法 Markdown，零风险 |
| 不加自动检测模式（检测用户是否打了 Markdown 符号） | 无必要，统一就是最简单的方案 |
