# 思忆便签 · 设计原则

> 版本：v2（2026-05-16）
> 设计方向：Things 3 极简风 · 蓝调 · 浅色默认

---

## 视觉语言

**极简 · 清晰 · 工具感**

### 核心理念

```
信任感 > 炫技
呼吸感 > 密度
一致性 > 个性
工具感 > 装饰感
```

- **默认浅色模式**：用户打开 App 看到的是白色背景，不是黑色。深色模式是设置里的选项。
- **蓝色是唯一强调色**：不和金色/紫色/渐变竞争。蓝色 = 效率工具的标准语言。
- **无线条分割**：间距代替分割线。Things 3 全 App 找不到一根分割线。
- **字体即设计**：系统原生字体 + 精确的字重/字号层级。

### 配色体系

色彩通过 CSS 自定义属性定义在 `src/styles/tokens.css` 中，所有组件引用变量，不硬编码颜色。

**浅色主题（默认）：**

```
--bg-primary:        #FFFFFF    主背景
--bg-secondary:      #F2F2F7    卡片/面板背景
--bg-tertiary:       #E5E5EA    输入框/选中态背景

--text-primary:      #000000    正文
--text-secondary:    rgba(60,60,67,0.6)  辅助信息
--text-tertiary:     rgba(60,60,67,0.3)  标签/说明
--text-disabled:     rgba(60,60,67,0.18) 禁用

--accent:            #007AFF    强调色（按钮、选中、FAB）
--accent-surface:    rgba(0,122,255,0.1)  强调色背景

--tone-smooth:       #34C759    顺利/完成
--tone-caution:      #FF9500    宜谨慎
--danger:            #FF3B30    危险/删除

--border-subtle:     rgba(60,60,67,0.1)
```

**深色主题：**

```
--bg-primary:        #000000
--bg-secondary:      #1C1C1E
--accent:            #0A84FF
--tone-smooth:       #30D158
--tone-caution:      #FF9F0A
--danger:            #FF453A
```

**纯黑主题（OLED）：** 同深色，但 `--bg-primary: #000000`，与 OLED 屏幕边框融为一体。

```

### 动画曲线

```

--ease-in:      cubic-bezier(0.4, 0, 1, 1)       缓入

### 主题

三种主题通过 `data-theme` 属性切换，所有颜色值使用 CSS 自定义属性，组件内不硬编码颜色。

| 主题 | 概述 | 适用场景 |
|------|------|---------|
| 浅色 (light) | 白色背景 #FFFFFF | **默认**，大多数环境 |
| 深色 (dark) | 深色背景 #000000 | 夜间/暗光环境 |
| 纯黑 (black) | 纯黑 #000000 | OLED 省电 |

支持"跟随系统"模式：通过 `prefers-color-scheme` 媒体查询自动切换。

## 参考信息的视觉层级

参考信息（黄历、八字、时辰）在视觉上必须**退后一步**，不与工具功能争抢注意力。

| 层级 | 内容 | 视觉权重 |
|------|------|---------|
| 第一层 | 日期、待办列表、FAB、底部 Tab | **最高** — 高对比度 |
| 第二层 | 黄历宜忌摘要（首页卡片） | **中** — 蓝色点缀，可折叠 |
| 第三层 | 完整参考详情（参考 Tab） | **低** — 弱对比，默认折叠 |

**具体规则：**
- 首页黄历摘要卡面积不超过屏幕的 20%，默认折叠
- 参考 Tab 内的卡片默认全部折叠
- 参考信息标题使用小号字体（13px），正文使用 11px
- 所有参考信息区域底部必须有免责声明（"依据传统历法理论，仅供决策参考"），字号 11px

## 交互原则

### 1. 单手可达

所有核心操作（新建待办、切换 tab、完成待办）在手机下半屏可完成。FAB 固定右下，tab 栏固定底部。

### 2. 手势为王

| 手势 | 操作 | 反馈 |
|------|------|------|
| 右滑待办 | 标记完成 | 绿色背景 + 勾选 + 触感 |
| 左滑待办 | 删除 | 红色背景 + 撤销 toast + 触感 |
| 长按待办 | 操作菜单 | 底部表单滑出 |
| 下拉首页 | 刷新 | 旋转指示器 |
| 下滑底部表单 | 关闭 | 跟随手指 + 弹性动画 |

### 3. 触感反馈

所有操作在 100ms 内给出视觉反馈。按钮按下即缩放（scale 0.97），松开回弹。使用 `navigator.vibrate()` 提供触感，无振动硬件时静默失败。

### 4. 空状态即引导

没有数据时不显示空白页面。每个空状态应该告诉用户：
- 这里是什么（标题）
- 为什么是空的（说明）
- 下一步做什么（操作按钮）

## 设计规范 checklist

每个界面交付前检查：

- [ ] 是否使用了 CSS 变量而非硬编码颜色？
- [ ] 是否在 3 个主题 + 系统跟随模式下都测试了？
- [ ] 按钮/交互元素是否 ≥44px？
- [ ] 是否有空状态？
- [ ] 是否有加载状态/过渡？
- [ ] 文字是否使用了正确的措辞（无玄学表述）？
- [ ] 参考信息是否标注了来源声明？
- [ ] 参考信息是否视觉权重低于工具功能（蓝色点缀、面积<20%、默认折叠）？
