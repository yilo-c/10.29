# 思忆便签 · 页面与流程

## 导航结构

```
底部 Tab 栏（4 项）
├── 今天 (首页)   ← 默认打开
├── 参考
├── 笔记
└── 设置
```

每个 tab 对应一个独立页面。用户通过底部 tab 栏切换。不设二级路由（无堆栈导航），所有深层操作使用底部表单（Sheet）或模态弹出。

## 页面一：今天（首页）

**定位**：App 的核心场景——每日简报 + 今日待办。

### 布局

```
┌──────────────────────────────────┐
│ 5月15日 周五                      │  ← DateHeader
│ 农历三月廿八 甲辰年 己丑日         │  ← LunarInfo（点击展开详情）
├──────────────────────────────────┤
│ ┌──────────────────────────────┐ │
│ │ 宜 签约·出行·纳财 | 冲猴 煞南 ▼│ │  ← AlmanacCard（默认折叠一行）
│ └──────────────────────────────┘ │
├──────────────────────────────────┤
│                                   │
│ 待办列表                          │
│                                   │
│ ┌─ ☐ 合同评审  🔔 14:00 ── 高 ─┐│  ← TodoItem
│ │   📂 工作                      ││
│ └────────────────────────────────┘│
│ ┌─ ☐ 买礼物 ─────────────── 中 ─┐│
│ │   📂 个人  5月20日             ││
│ └────────────────────────────────┘│
│ ┌─ ☑ 晨会 ─────────────── 低 ──┐│
│ └────────────────────────────────┘│
│                                   │
│         今天还没有待办             │  ← 空状态
│     点击下方 + 创建第一条          │
│                                   │
├──────────────────────────────────┤
│                            [+]   │  ← FAB（右下固定）
├──────────────────────────────────┤
│  今天  │ 参考 │ 笔记 │ 设置      │  ← Tab Bar
└──────────────────────────────────┘
```

### 组件说明

**DateHeader**
- 显示公历日期 + 星期
- 下行显示农历日期 + 干支日
- 点击跳转到日期选择器（参考其他日期的黄历）

**AlmanacCard**
- 默认折叠，仅显示一行摘要（如"宜 签约·出行·纳财 | 冲猴 煞南"），占屏幕不到 8%
- 点击展开查看完整宜忌列表 + 冲煞 + 方位（展开后面积不超过屏幕 20%）
- 展开后下方出现极小的免责文字（10px，"依据传统历法理论，仅供决策参考"）
- 有出生信息时，展开后额外显示八字日主一行提示（非独立卡片）
- 设计意图：效率用户扫一眼就过去了，不会被黄历信息打断。参考用户可以点开看详情。

**TodoList**
- 仅显示今日到期的待办（通过 `dueDate` 筛选），或设置了提醒时间的待办
- 按优先级排序：高 > 中 > 低
- 已完成待办置于列表底部，灰显+划线
- 空列表显示空状态指引

**FAB（浮动操作按钮）**
- 右下固定，52px 金色圆形
- 阴影 `0 4px 16px rgba(201,167,92,0.3)`
- 点击弹出 NewTodoSheet

### 交互

| 操作 | 响应 |
|------|------|
| 下拉列表 | 刷新黄历数据（旋转指示器 + 更新 AlmanacCard） |
| 点击 AlmanacCard 箭头 | 展开/折叠完整宜忌列表 |
| 点击日期 | 弹出日期底部表单（预留：查看其他日期的待办） |
| 点击 FAB | 弹出新建待办底部表单 |
| 右滑待办 | 标记完成（绿色背景动画 + 触感） |
| 左滑待办 | 删除 + 撤销 toast（红色背景 + 触感） |
| 长按待办 | 弹出操作底部表单 |
| 点击待办 | 弹出操作底部表单 |

### 状态

| 状态 | 表现 |
|------|------|
| 首次使用 | 显示今日参考 + "今天还没有待办" 空状态 |
| 有已完成的今日待办 | 底部灰色分隔线 + 已完成待办列表 |
| 所有待办已完成 | 全部灰显 + "今天的事情都完成了" 提示 |
| 有提醒将触发 | 待办右侧显示 🔔 图标 + 提醒时间 |
| 提醒触发 | 底部滑入 ReminderBar |

## 页面二：参考

**定位**：传统文化的"词典"页——查看但不推送。用户需要时主动翻阅，不需要时不存在。

**设计原则**：参考 Tab 虽然排在导航第二位，但它的视觉权重和交互权重低于首页。黄金法则是：效率用户永远不会被参考内容干扰，参考用户永远不会觉得参考内容太少。

### 布局

```
┌──────────────────────────────────┐
│ 参考                              │
│ 依据传统历法理论，仅供决策参考      │  ← 顶部声明
├──────────────────────────────────┤
│                                   │
│ ┌── 今日评分 ──────────────────┐ │
│ │ 较顺利 ████████░░░░ 7/10     │ │  ← DayRating
│ │ 今日诸事较顺，宜按计划推进     │ │      评分条 + 摘要引用
│ └──────────────────────────────┘ │
│                                   │
│ ┌── 今日黄历 ▼ ───────────────┐ │  ← 默认展开
│ │ 宜 签约 出行 纳财 交易       │ │     完整宜忌列表
│ │ 忌 动土 安葬 伐木            │ │
│ │ 冲猴 煞南                    │ │
│ │ 喜神 西南 财神 正北 福神 正东│ │

│ └──────────────────────────────┘ │
│                                   │

│ │       [罗盘可视化]            │ │  ← CSS 绘制罗盘

│  今天  │ 参考 │ 笔记 │ 设置      │  ← Tab Bar
└──────────────────────────────────┘
```

### 组件说明

**DayRating**
- 5 段水平评分条，当前等级高亮为哑金色（非交互金色，避免误认为按钮）
- 等级：较顺利 · 平和 · 宜谨慎（仅三档，刻意避免"大吉/大凶"等命理术语）
- 下方显示 `generateSummaryQuote()` 输出的简短摘要（一句话，不超过 20 字）
- 默认折叠在黄历卡内部，不作为独立卡片展示
- 视觉权重：低于待办列表，高于免责声明

**黄历卡**
- 从 `getHuangli(new Date())` 获取完整数据
- 显示所有宜、忌（不截断）
- 显示冲煞、喜神/财神/福神方位
- 显示廿八宿

**八字卡**
- 从 `calculateBazi()` 获取数据
- 显示四柱（年/月/日/时 天干地支）
- 五行统计（使用 `getWuxingColor` 着色圆点）
- 日主、身强/弱、喜用神
- 未填写出生信息时显示"填写生日以查看"引导

**时辰卡**
- 自动计算当前时辰（子丑寅卯...）
- 显示当前时辰的天干地支
- 显示奇门排盘简略信息（星、门、宫）
- 根据时辰 + 事项类型给出简短建议

**罗盘卡**
- 使用 `useCompass()` 读取设备朝向
- CSS 绘制罗盘（N/E/S/W 四向 + 东北/东南/西南/西北）
- 指针旋转跟随 heading
- 对比今日喜/财/福神方位，一致时高亮

### 交互

| 操作 | 响应 |
|------|------|
| 下拉 | 刷新黄历（重新计算当日数据） |
| 点击卡片标题 | 展开/折叠 |
| 点击八字引导 | 跳转到设置页（填写出生信息） |
| 点击罗盘 | 首次弹出权限请求，后续开始追踪朝向 |

**默认状态**：所有卡片默认折叠。用户展开某张卡片后，其他卡片保持折叠——同一时间只展示一类参考信息，避免信息轰炸感。若用户上次离开参考 Tab 时有展开的卡片，下次回来保持该卡片展开（但不自动展开其他卡片）。

### 交互

| 操作 | 响应 |
|------|------|

### 编辑模式

笔记编辑在当前卡片位置或通过 Sheet 展开：
- 标题输入 + 正文 textarea
- 纯文本 / Markdown 切换
- 保存/取消按钮
- 删除按钮（红色）

## 全局 UI 组件

### Sheet（底部表单）
- 从底部滑入，背景变暗
- 顶部有拖拽手柄
- 向下拖拽关闭
- 最大高度 85% 屏幕
- 圆角顶部 16px

### Toast（操作反馈）
- 底部固定，短暂显示后消失
- 支持撤销操作（如删除待办后的"撤销"按钮）
- 动画：fadeInUp + 3s 后 fadeOutDown

### ReminderBar（提醒栏）
- 闹钟触发时从底部滑入
- 金色背景，显示待办文字
- 按钮：关闭 / 稍后提醒（5 分钟 / 15 分钟）
- Web Audio API 循环响铃
- 配合 Notification API 后台通知

### Badge（优先级标记）
- 小圆点 + 文字
- 高 = 红色 / 中 = 金色 / 低 = 绿色

### Divider（分割线）
- 1px 高度，`--border-subtle` 颜色
- 上下 margin 12px

## 用户流程

### 核心流程：早晨查看 + 规划

```
打开 App
  → 首页显示今日日期 + 黄历摘要
  → 下拉刷新黄历
  → 浏览今日待办
  → 点击 FAB 新建待办
    → 填写内容 → 选择事项类型 → 看到该类型的今日宜忌参考
    → 设置截止日期 → 设置提醒时间
    → 保存
  → 待办出现在列表中
```

### 决策流程：不确定今天适不适合做某事

```
打开 App
  → 在首页 AlmanacCard 看今日宜忌
  → 或切换到参考 tab 查看完整详情
  → 判断后再回来新建待办
```

### 笔记流程

```
切换到笔记 tab
  → 选择文件夹
  → 点击 FAB 新建笔记
  → 输入标题和内容
  → 保存
  → 笔记出现在列表中
```
