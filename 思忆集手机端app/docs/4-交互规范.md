# 思忆便签 · 交互规范

## Tab 切换

**触发**：点击底部 tab 栏图标
**反馈**：
1. 被点击的 tab 图标立即变为金色
2. 内容区执行 `fadeSlideIn` 动画（200ms）
3. 轻触振动（10ms）
**CSS**：
```css
@keyframes fadeSlideIn {
  from { opacity: 0; transform: translateY(6px); }
  to { opacity: 1; transform: translateY(0); }
}
```
**注意**：如果用户已在当前 tab，再次点击不做任何事。

## 待办滑动操作

### 右滑完成

**触发**：触摸待办行，向右滑动 > 40px
**过程**：
1. 手指移动时，待办行跟随 `translateX(${offset}px)`
2. 背景渐变为绿色调（`rgba(111,179,137,0.08)`）
3. 超过 40px 阈值后视觉锁定（绿色加深）
4. 松手后：
   - 超过阈值 → `toggleTodo(id)` + 振动 12ms + 行滑出 + 列表重排
   - 未超过 → 弹性回弹至原位（200ms ease-out）

### 左滑删除

**触发**：触摸待办行，向左滑动 > 40px
**过程**：
1. 手指移动时，待办行跟随 `translateX(${offset}px)`
2. 背景渐变为红色调（`rgba(229,115,115,0.08)`）
3. 超过 40px 阈值后视觉锁定
4. 松手后：
   - 超过阈值 → 删除 + 振动 15ms + 底部 toast"已删除 + 撤销"
   - 未超过 → 弹性回弹
5. 撤销按钮：3 秒内点击恢复待办，toast 消失
6. 3 秒未操作，toast 自动消失，删除生效

### 长按

**触发**：触摸待办行 > 500ms，移动 < 10px
**反馈**：弹出 TodoActionSheet（底部表单）
**注意**：长按期间如果手指移动 > 10px，取消长按，转为滑动模式

## Sheet（底部表单）操作

### 打开
1. 背景从透明变为 `rgba(0,0,0,0.5)`（120ms）
2. Sheet 从 `translateY(100%)` 滑入到 `translateY(0)`（280ms ease-out）
3. 顶部 drag handle 淡入

### 关闭
**方式 1：向下拖拽**
1. 手指从 drag handle 区域（顶部 100px）开始拖动
2. Sheet 跟随 `translateY(${dy}px)`，带阻力系数 0.5
3. 超过 80px 松手 → 关闭动画
4. 未超过 80px 松手 → 弹性回弹

**方式 2：点击背景**
- 直接触发关闭动画

**方式 3：操作完成**
- 例如保存待办后自动关闭，无拖拽动画，直接滑出

## 下拉刷新

**触发**：待办列表滚动到顶部后继续下拉
**过程**：
1. 列表顶部出现刷新指示器（旋转的圈圈或箭头）
2. 下拉超过 60px 时进入可刷新状态
3. 松手后：
   - 指示器变为加载旋转动画
   - 执行刷新：`getHuangli(new Date())` 重新计算
   - 完成后 AlmanacCard 更新
   - 指示器消失（300ms）

## 按钮点击

### 通用按钮（Button）
**按下**：`transform: scale(0.97)`（60ms ease-out）
**松开**：`transform: scale(1)`（120ms ease-out）+ 振动 8ms
**禁用**：opacity 0.35，cursor not-allowed，无缩放效果

### FAB
**按下**：`transform: scale(0.92)` + 阴影缩小
**松开**：`transform: scale(1)` + 阴影恢复 + 振动 8ms

- 220ms ease-out

## 提醒触发（ReminderBar）

### 触发条件
定时器检测到某待办的 `reminderTime` ≤ 当前时间，且 `reminderSnoozedUntil` 为空（或 ≤ 当前时间）。

### 过程
1. 如果 `Notification.permission === 'granted'`，发送系统通知（标题：待办文字，内容：提醒时间）
2. ReminderBar 从底部滑入（250ms），覆盖在 tab 栏上方
3. Web Audio API 开始循环播放闹铃（440Hz / 660Hz 交替，1 秒周期）
4. 用户操作：
   - **关闭**：停止闹铃 + `clearReminder()` + ReminderBar 滑出
   - **稍后提醒 5 分钟**：停止闹铃 + `snoozeReminder(id, 5)` + ReminderBar 滑出
   - **稍后提醒 15 分钟**：同上
5. 如果 App 在后台，仅使用 Notification（前台才有音频闹铃）

### 权限
App 启动时请求 `Notification.permission`。用户拒绝后不再请求，仅使用 Web Audio 前台响铃。

## 罗盘

### 权限
iOS 需要用户主动触发权限请求。罗盘卡首次展开时显示"点击启用罗盘"按钮。
点击后调用 `useCompass().requestPermission()`。

### 动画
罗盘指针使用 `transform: rotate(${heading}deg)`。
指向通过 `requestAnimationFrame` 做 1° 节流，避免过度渲染。

### 校准
iOS 设备可能需要做"∞"字手势校准罗盘。罗盘卡内显示校准提示。

### 无传感器回退
设备无磁力计时显示"设备不支持方位传感器"，改用静态方向标注（显示今日喜神/财神方位）。

## 触感振动速查

| 操作 | 时长 | 感觉 |
|------|------|------|
| Tab 切换 | 10ms | 轻触 |
| 按钮点击 | 8ms | 确认 |
| 完成待办 | 12ms | 满意 |
| 删除待办 | 15ms | 警示 |
| 滑动过阈值 | 6ms | 到位 |
| 下拉刷新触发 | 10ms | 锁定 |

所有振动通过 `navigator.vibrate()` 实现，不依赖于 Native 插件，在桌面端不报错。
