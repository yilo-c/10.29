# 思忆便签 · 视觉设计规范 v2

> 设计方向：Things 3 极简风。浅色默认，蓝色强调，SF Symbol 图标，大留白。

---

## 1. 设计原则

```
信任感 > 炫技
呼吸感 > 密度
一致性 > 个性
工具感 > 装饰感
```

- **默认浅色模式**：用户打开 App 看到的是白色背景，不是黑色。暗色模式是设置里的选项。
- **蓝色是唯一强调色**：不和金色/紫色/渐变竞争。蓝色 = 效率工具的标准语言。
- **无线条分割**：间距代替分割线。Things 3 全 App 找不到一根分割线。
- **字体即设计**：系统原生字体 + 精确的字重/字号层级。

## 11. 浅色 vs 深色 切换

- 默认浅色。用户在设置中可切换到深色/纯黑。
- 所有颜色通过 CSS 变量切换，组件不判断主题。
- 深色模式下，`border-subtle` 微微可见，`bg-glass` 比浅色模式略亮。
- 纯黑模式下，`bg-primary = #000000`，和 OLED 屏幕边框融为一体。
