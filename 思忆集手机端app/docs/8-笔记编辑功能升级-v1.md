## 2. 分阶段实施计划

### Phase 1 — 编辑器体验对齐（高价值，中工作量）

**2.1 统一新建/编辑为 NoteEditorSheet**

- 新建笔记在保存时调用 `addFloatingNote`，编辑时调用 `updateFloatingNote`

```

```

**2.2 格式化工具栏**

键盘上方固定横条，点击在当前光标位置插入 Markdown 符号：

```
┌─────────────────────────────────────────┐
│  B  │  I  │  H1  │  H2  │  ≡  │  ☐  │  ❝  │  ─  │
└─────────────────────────────────────────┘
```

| 按钮 | 插入内容 | Markdown 结果 |
|------|---------|-------------|
| **B** | `**选中的文字**` | `**bold**` |
| *I* | `*选中的文字*` | `*italic*` |
| H1 | `# 标题` | 标题行 |
| H2 | `## 标题` | 二级标题 |
| ≡ | `- 列表项` | 无序列表 |
| ☐ | `- [ ] 待办项` | 待办列表 |
| ❝ | `> 引用` | 引用块 |
| ─ | `---` | 分割线 |

实现方式：

```tsx
function FormatToolbar({ textareaRef, onInsert }: FormatToolbarProps) {
  const insert = (template: string) => {
    const ta = textareaRef.current
    if (!ta) return
    const start = ta.selectionStart
    const end = ta.selectionEnd
    const selected = content.substring(start, end)
    const insertion = template.replace('$TEXT', selected || '文本')
    // 插入到光标位置
    onInsert(insertion, start, end)
  }

  return (
    <div style={toolbarStyle}>
      <ToolBtn label="B" onClick={() => insert('**$TEXT**')} />
      <ToolBtn label="I" onClick={() => insert('*$TEXT*')} />
      <ToolBtn label="H1" onClick={() = > insert('# $TEXT')} />
      {/* ... */}
    </div>
  )
}
```

文件改动：新建 `NotesFormatToolbar.tsx` 组件，集成到 `NoteEditorSheet`

**2.3 接入撤销/重做**

在 NoteEditorSheet 的 `onChange` 中调用 `onContentEdit(note.id)`：

```tsx
// NoteEditorSheet.tsx
import { onContentEdit, flushPendingEdit } from '@desk-notes/shared'

// content onChange
const handleContentChange = (value: string) => {
  setContent(value)
  if (note) onContentEdit(note.id)
}

// 组件卸载时 finalize
useEffect(() => {
  return () => { if (note) flushPendingEdit() }
}, [note])
```

文件改动：`NoteEditorSheet` 内 `onChange` + `useEffect` cleanup

**2.5 相对时间 + 时间分组**

替换 `formatDate` 为完整的相对时间格式化：

```tsx
function formatRelativeTime(ts: number): string {
  const diff = Date.now() - ts
  if (diff < 60000) return '刚刚'
  if (diff < 3600000) return `${Math.floor(diff / 60000)} 分钟前`
  if (diff < 86400000) return `${Math.floor(diff / 3600000)} 小时前`
  if (diff < 172800000) return '昨天'
  if (diff < 259200000) return '前天'
  // 今年内显示月/日，跨年显示年/月/日
  const d = new Date(ts)
  const now = new Date()
  if (d.getFullYear() === now.getFullYear()) {
    return `${d.getMonth() + 1}/${d.getDate()}`
  }
  return `${d.getFullYear()}/${d.getMonth() + 1}/${d.getDate()}`
}
```

列表按日分组（在 `filtered.map` 外层包分组逻辑）：

```tsx
// 分组
const grouped = useMemo(() => {
  const groups: { label: string; notes: FloatingNote[] }[] = []
  let today: FloatingNote[] = []
  let yesterday: FloatingNote[] = []
  // ...分配逻辑
  if (today.length) groups.push({ label: '今天', notes: today })
  if (yesterday.length) groups.push({ label: '昨天', notes: yesterday })
  // ...
  return groups
}, [filtered])

// 渲染
{grouped.map(group => (
  <div key={group.label}>
    <div style={groupHeaderStyle}>{group.label}</div>
    {group.notes.map(note => <NoteCard key={note.id} ... />)}
  </div>
))}
```

文件改动：`NotesView.tsx` — 新增 `formatRelativeTime`、分组逻辑、组头样式

**2.6 自动保存**

在 NoteEditorSheet 中增加 debounce 自动保存：

```tsx
// NoteEditorSheet
const autoSaveTimer = useRef<ReturnType<typeof setTimeout> | null>(null)

const handleContentOrTitleChange = useCallback(() => {
  if (autoSaveTimer.current) clearTimeout(autoSaveTimer.current)
  autoSaveTimer.current = setTimeout(() => {
    if (note) {
      onUpdate(note.id, {
        title: title || '无标题',
        content,
        updatedAt: Date.now(),
      })
    }
  }, 1500)
}, [note, title, content, onUpdate])
```

保存指示器（可选）：

```tsx
{saving && <span style={{ color: 'var(--text-disabled)', fontSize: 12 }}>保存中...</span>}
{saved && <span style={{ color: 'var(--tone-smooth)', fontSize: 12 }}>已保存</span>}
```

文件改动：`NoteEditorSheet` — 新增 `useRef` 定时器 + 保存状态指示
