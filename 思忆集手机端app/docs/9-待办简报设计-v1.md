# 思忆便签 · 待办简报设计 v1

> 目标：待办页面增加简报区，将"待办列表"升级为"每日工作台"

---

## 1. 设计背景

### 当前待办页面布局

```
┌──────────────────────────────────┐
│ 🔍 搜索                          │
├──────────────────────────────────┤
│ [今日:3] [全部:12] [工作] [个人]   │ ← 分类筛选
├──────────────────────────────────┤
│ [待完成:8] [已完成:4] [逾期:2] [排序]│ ← 状态筛选
├──────────────────────────────────┤
│ ☐ 合同评审     🔔 14:00    高    │
│ ☐ 买礼物       5/20        中    │
│ ☑ 晨会                     低    │
│ ...                              │
├──────────────────────────────────┤
│ 已完成 4 项          [清除已完成]  │
└──────────────────────────────────┘
```

### 问题

- 待办列表"扁平"展开，缺乏上下文信息
- 用户打开"待办" tab 第一眼看不到概览
- 逾期、今日任务、完成率 等信息散落在筛选 chips 中
- DateHeader（日期头）和 AlmanacStrip（黄历条）存在但没有在 TodoView 中使用

### 定位

待办页面应该是用户的"每日工作台"，简报区提供一目了然的日概览。

---

## 2. 方案：简报区布局

### 整体结构

```
┌──────────────────────────────────┐
│ 5月16日 周五                       │ ← DateHeader（已有组件）
│ 农历四月初一 · 甲辰年              │
├──────────────────────────────────┤
│ ┌── 今日简报 ──── 折叠 ────────┐ │
│ │ 📋 今日待办 5 项              │ │ ← BriefingCard（新）
│ │ ⏰ 逾期 2 项                  │ │
│ │ 📊 进度 ▰▰▰▰▰▰▰▰▰░░ 82%    │ │
│ │ 🔥 连续完成 7 天              │ │
│ │ ────                          │ │
│ │ 高: 2  中: 5  低: 1          │ │
│ │ ────                          │ │
│ │ 快速添加今日待办 +             │ │ ← Quick add
│ └──────────────────────────────┘ │
├──────────────────────────────────┤
│ ┌ 宜 签约·出行·纳财 | 冲猴 煞南 ┐│ ← AlmanacStrip（已有组件）
│ └──────────────────────────────────┘
├──────────────────────────────────┤
│ [待完成:8] [已完成:4] [逾期:2]    │
│                              [排序]│
├──────────────────────────────────┤
│ ☐ 合同评审     🔔 14:00    高    │
│ ...                              │
└──────────────────────────────────┘
```

### 2.1 BriefingCard 组件

#### 上部：核心指标

| 指标 | 数据来源 | 条件 |
|------|---------|------|
| 今日待办 | `todos.filter(t => !t.done && isToday(t.dueDate)).length` | 始终显示 |
| 逾期数量 | `todos.filter(t => !t.done && t.dueDate < now && !isToday(t.dueDate)).length` | > 0 时高亮 |
| 完成进度 | 今日完成 / (今日完成 + 今日待办) | 有今日待办时显示 |
| 连续完成天数 | 基于 `doneAt` 计算（需新增字段） | > 0 时显示 |

#### 中部：优先级分布

```
高: 2   中: 5   低: 1   (仅未完成)
```

各优先级用对应颜色圆点 + 数字。

#### 下部：快速添加

"快速添加今日待办" 按钮，点击直接打开 NewTodoSheet 并预填今日日期。

### 2.2 折叠交互

- 简报区支持折叠/展开
- 默认展开
- 折叠后仅显示一行摘要：

```
📋 今日 5 项 · 逾期 2 项 · ▰▰▰▰▰▰▰▱▱▱ 70%           [展开]
```

- 折叠状态存入 localStorage（或 Zustand store）

### 2.3 数据流

```
useStore.todos → useMemo 计算简报数据 → BriefingCard 展示

计算指标（全部在 useMemo 中，无额外渲染开销）：
  - todayTodos:  今日到期 & 未完成
  - overdueTodos: 过期 & 未完成
  - doneToday:   今日完成的
  - priorityDist: { high, mid, low } 各优先级数量
  - completionPct: 今日完成率
```

## 4. 效果预期

| 维度 | 改前 | 改后 |
|------|------|------|
| 信息密度 | 仅列表，无上下文 | 概览 + 列表 |
| 决策效率 | 用户需自行扫描列表找今天/逾期任务 | 一眼知道今天有几项、逾期多少 |
| 产品质感 | 纯列表工具 | Things 3 风格每日工作台 |
| 功能联动 | 日期和黄历信息在别处 | 待办页面一站式展现 |
